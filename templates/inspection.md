# ביקור ובדיקה

- רכב ותאריך:
- מי הזמין את הבדיקה ומי ביצע אותה?
- האם מזהי הרכב תואמים לדוח?

- [ ] התאמת הרכב, המסמכים וסמכות המוכר
- [ ] התנעה, נורות אזהרה וסימנים חריגים
- [ ] צמיגים, מיזוג, אביזרים ומפתחות
- [ ] התאמה פיזית לנוסעים, מטען וחניה
- [ ] נסיעת מבחן בתנאים מותרים ובטוחים
- [ ] בדיקה מקצועית עצמאית וממוקדת לווריאנט
- [ ] פירוש כתוב לממצאים לא ברורים
- [ ] הצעת מחיר לתיקונים מהותיים
