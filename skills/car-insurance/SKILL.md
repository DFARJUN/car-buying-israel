# Car Insurance

## Shared contract

Find the repository root containing `app/model.mjs` and read `docs/evidence.md` there before giving recommendations. Repository paths below are relative to that root, even when this skill is loaded through a discovery directory. Read `my-car/session.md` if it exists. Use Hebrew for questions and outputs. Save private work only under `my-car/`; use fictional data in public contributions. Ask for missing decision inputs as explicit questions. Conclude with recommendation, evidence, tradeoff, and one next action. Record the current stage and unresolved blockers in the session. Do not contact anyone or spend money without explicit authorization.

## Compare coverage, not just premium

Ask about intended drivers, use, annual distance, cover sought and start time. Request only the personal data needed for analysis; direct the buyer to give sensitive identifiers to the insurer rather than store them in the public repository.

Compare compulsory, third-party and comprehensive components separately. Record quoted premium, named/young driver restrictions, deductible by claim type, repair network, theft conditions, replacement vehicle, roadside help, exclusions and excesses. Do not assume a quote is bound coverage or that all policies cover the same drivers.

Use current insurer policy documents and official guidance where legal requirements matter. Record written confirmation of effective date/time and vehicle details before handover. Route annual premium into car-budget without double-counting a package that already includes it.

Output a like-for-like table with unanswered questions and a recommended next clarification. Never bind coverage, cancel an existing policy or submit sensitive information without explicit authorization.
