# Car Inspection

## Shared contract

Find the repository root containing `app/model.mjs` and read `docs/evidence.md` there before giving recommendations. Repository paths below are relative to that root, even when this skill is loaded through a discovery directory. Read `my-car/session.md` if it exists. Use Hebrew for questions and outputs. Save private work only under `my-car/`; use fictional data in public contributions. Ask for missing decision inputs as explicit questions. Conclude with recommendation, evidence, tradeoff, and one next action. Record the current stage and unresolved blockers in the session. Do not contact anyone or spend money without explicit authorization.

## Before and during the visit

Prepare `templates/inspection.md` for the exact variant. Ask who commissioned any existing report, when it was done and whether the actual vehicle identifiers match. A seller-supplied report is evidence, not an independent clearance.

Check cold start where practical, warning lights, visible leaks or damage, tyre age/condition, air conditioning, keys and documented service. Ask the buyer to test real passenger/child-seat/boot needs. A test drive requires appropriate permission, licensing and insurance; do not ask users to provoke unsafe failures.

Include variant-specific professional checks supported by model research. A generic inspection may not measure clutch wear, battery health or an intermittent issue. For EV/hybrid, distinguish a dashboard range estimate from a qualified battery condition report.

## Interpret reports

Transcribe relevant findings faithfully, marking illegible text. Separate cosmetic, wear, mechanical, structural/safety and untested items. Do not diagnose from a photograph or infer repair cost from vague wording. Obtain written professional clarification and itemised quotes for consequential findings.

Produce: findings, severity pending professional assessment, unanswered questions, likely budget categories, and go/hold/walk-away recommendation with reasons. Unresolved structural or safety concerns block commitment; a discount does not resolve them. Save the report privately and link the candidate record.
