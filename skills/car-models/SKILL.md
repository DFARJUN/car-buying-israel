# Car Models

## Shared contract

Find the repository root containing `app/model.mjs` and read `docs/evidence.md` there before giving recommendations. Repository paths below are relative to that root, even when this skill is loaded through a discovery directory. Read `my-car/session.md` if it exists. Use Hebrew for questions and outputs. Save private work only under `my-car/`; use fictional data in public contributions. Ask for missing decision inputs as explicit questions. Conclude with recommendation, evidence, tradeoff, and one next action. Record the current stage and unresolved blockers in the session. Do not contact anyone or spend money without explicit authorization.

## Compare variants, not badges

Read the buyer brief before research. Find current primary specifications for the Israeli market: importer specification sheet, owner/service manual, government registration data, manufacturer recall information, and relevant crash-test report. Use reliable independent testing for real-world experience and label forum anecdotes as anecdotes.

Record make, model, generation, model year versus first registration, trim, engine, transmission and factory safety equipment. A model year can contain two generations. A warning-only aftermarket device is not factory automatic braking. Overseas equipment and recall applicability do not automatically transfer to Israeli cars.

For reliability, distinguish a documented failure mode from its unmeasured frequency; record applicable engine codes or production ranges only when the source supports them. Do not grant automatic reliability points to an engine or gearbox category. For EVs and hybrids, include battery warranty, battery condition evidence and charging practicality.

Produce 3-5 variants with fit, key tradeoff, source date, exact uncertainty and what a physical visit must test. Use `templates/model-research.md` and record model research in `my-car/models/`. Save a source-linked summary in the candidate model_research field; reuse research only for the same verified variant. Candidate-specific condition can change the recommendation independently of model-level reputation.
