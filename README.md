# הרכב הבא שלי 🚗

**ליווי רכישת רכב בישראל עם AI, מהשאלה ״מה בכלל מתאים לי?״ ועד קבלת המפתחות.**

13 סקילים ל־Codex ול־Claude Code, מערכת השוואת רכבים ומחשבוני עלות ומימון. ליד שנייה, חדש ו־0 ק״מ. קוד פתוח, ברישיון MIT.

לא צריך להכיר את שוק הרכב או לדעת לכתוב קוד. רוב התהליך מתנהל בשיחה עם האייג׳נט. הוא שואל, חוקר, מחשב ומעדכן את התיק. האתר הוא סיכום של הדברים, ולא מקום שצריך למלא בו טבלאות.

## הפלואו

**מה חשוב לי? → מחקר דגם → מחקר לפי מספר רכב → ציון AI אישי → עלות משוערת לשלוש שנים.**

מתחילים בשימוש, תנאי חובה ומשקולות. הסוכן חוקר את הגרסה ואת הרכב המסוים, נותן ציון מנומק בכל ממד, ואז מציג בנפרד כמה צפוי לעלות להחזיק אותו 36 חודשים. [איך המחקר והדירוג עובדים](docs/ai-scoring.md).

## מה מקבלים?

- **תהליך אישי:** הסוכן שואל על הצרכים שלכם, שומר החלטות וממשיך מהמקום שבו עצרתם.
- **השוואה מסודרת:** מחיר, גרסה, ק״מ, סטטוס, מקורות, הערות ודירוג אישי לכל מועמד.
- **שלושה מדדים נפרדים:** עמידה בתנאי חובה, דירוג לפי המשקולות שלכם ועלות עד המכירה.
- **מחשבון שקוף:** ירידת ערך, ביטוח, דלק או טעינה, טיפולים, תיקונים, רישוי ומימון. כולל בלון ויתרת חוב במכירה.
- **הכנה לרכישה:** שאלות למוכר, בדיקת היסטוריה, נסיעת מבחן, פירוש דוח, אחריות, מיקוח, ביטוח ומסירה.

## מתחילים כאן

### 1. מורידים את הפרויקט

לחצו על הכפתור הירוק **Code**, ואז **Download ZIP**, וחלצו את התיקייה. לחלופין, למי שמשתמש ב־Git:

```bash
git clone https://github.com/DFARJUN/car-buying-israel.git
cd car-buying-israel
```

### 2. פותחים ב־Codex או ב־Claude Code

פתחו את התיקייה כפרויקט מקומי. צריך התקנה וחשבון פעיל בכלי שבחרתם; הריפו עצמו לא כולל מנוי ל־AI. הריצו בטרמינל מתוך התיקייה, או בקשו מהסוכן להריץ:

```bash
python3 tools/setup.py
```

הפקודה מחברת את תיקיית הסקילים לשני הכלים בתוך הפרויקט בלבד. היא לא משנה הגדרות במחשב ולא מתקינה חבילות. נדרש Python 3.10 ומעלה. ב־Windows השתמשו ב־WSL או הפעילו תמיכה בקישורים סימבוליים (Developer Mode). אם הפקודה `python3` אינה קיימת, אפשר להשתמש ב־`python` כשהוא Python 3.10 ומעלה.

לאחר מכן פתחו שיחה חדשה בפרויקט וכתבו:

> אני רוצה לקנות רכב בישראל. הפעל את car-buying-guide, שאל אותי מה חשוב לי, חקור דגמים ורכבים ספציפיים, הפק ציון AI ועלות לשלוש שנים, ועדכן לי את דף הסיכום. נהל את הקבצים בעצמך.

אפשר גם להפעיל במפורש: `$car-buying-guide` ב־Codex, או `/car-buying-guide` ב־Claude Code. אם הסקיל לא מופיע, פתחו מחדש את השיחה. ההוראות מיועדות לעבודה מקומית; שירותי ענן עשויים לטעון סקילים אחרת. [תיעוד Codex](https://learn.chatgpt.com/docs/build-skills) · [תיעוד Claude Code](https://code.claude.com/docs/en/skills).

אין Python או שההתקנה לא הסתדרה? אפשר להתחיל בשיחה ולבקש: ״קרא את AGENTS.md ואת skills/car-buying-guide/SKILL.md ועבוד לפיהם״.

### 3. האייג׳נט פותח את הסיכום

בקשו ממנו לפתוח את דף הסיכום. הוא שומר את המחקר וההשוואה ב־`my-car/comparison.json`, ומפעיל את השרת. להפעלה עצמאית מתוך התיקייה:

```bash
python3 tools/serve.py
```

פותחים בדפדפן את [מערכת ההשוואה המקומית](http://127.0.0.1:8772/app/). הטרמינל נשאר פתוח; `Ctrl+C` עוצר את השרת. אם הפורט תפוס: `python3 tools/serve.py --port 8773` ואז פותחים את אותה כתובת עם הפורט החדש.

בלי תיק רכישה, הדף ממתין לאייג׳נט. אחרי שהאייג׳נט שומר סיכום, האתר מציג אותו ומתעדכן כל חמש שניות. לשינוי צרכים, הוספת מודעה או מחקר נוסף, ממשיכים בשיחה.

אפשר לראות הדגמה פיקטיבית בלי AI:

```bash
python3 tools/serve.py --data examples/comparison.json
```

## מה רואים באתר?

- מה חשוב לכם, תנאי החובה והמשקולות שסוכמו.
- המלצה נוכחית, הנימוק, הפשרה והפעולה הבאה.
- מחקר הדגם ומחקר הרכב לפי מספר רישוי, עם מקורות ומידע חסר.
- ציון AI מנומק לצד עלות משוערת לשלוש שנים ופירוט הוצאות.
- השוואה של שניים או שלושה מועמדים, סינון ומיון.

במצב המחובר האתר לקריאה בלבד. הוא אינו משנה את הקובץ שהאייג׳נט מנהל. כלים ידניים קיימים כחלופה אופציונלית בלבד כשאין קובץ מחובר; שם נדרשים ייצוא וגיבוי של נתוני הדפדפן.

## דוגמאות לשיחה

> יש לי שלוש מודעות. הוסף אותן להשוואה, סמן מה לא ידוע ותגיד מה לשאול כל מוכר.

> הסוכנות מציעה רכב 0 ק״מ עם אחריות. בדוק מה כתוב בהצעה, מתי האחריות התחילה ומה חסר.

> ההחזר החודשי נמוך, אבל יש בלון. כמה חוב יישאר כשארצה למכור בעוד שלוש שנים?

> קיבלתי דוח בדיקה. הפרד בין ממצאים, שאלות למכון ותנאים שצריכים להיפתר לפני קנייה.

## מה צריך לדעת?

היישום מקומי, ללא אנליטיקה, פרסומות, פונטים מרוחקים או חשבון נוסף. במסלול הרגיל הנתונים נשמרים בקובץ פרטי במחשב ומוצגים דרך שרת מקומי שמאזין רק ל־127.0.0.1. הם אינם נשלחים לשירות ענן על ידי האתר. במסלול הידני בלבד, הנתונים נשמרים בדפדפן. לחיצה על קישור חיצוני פותחת את האתר המקושר. הנתונים שתשתפו עם כלי AI כפופים לשירות שבו אתם משתמשים.

שמרו מסמכים ונתונים אישיים רק ב־`my-car/`, שמוחרגת מ־Git. השרת המקומי מגיש את הממשק ואת קובץ ההשוואה שנבחר בלבד; הוא אינו מגיש את שאר המסמכים בתיק הרכישה. אל תעלו קובצי ייצוא אישיים ל־Issues או ל־PR.

הגרסה הזו אינה סורקת אוטומטית לוחות מודעות, אינה פונה למוכרים ואינה מבצעת רכישות. מחקר ברשת תלוי ביכולות ובהרשאות של כלי ה־AI. הלוואות משתנות או צמודות דורשות בדיקה נפרדת. [הנוסחאות והמגבלות](docs/calculations.md) · [מקורות](docs/sources.md) · [כללי ראיות](docs/evidence.md).

לשמירה מאומתת ולחישובי האייג׳נט נדרש Node.js 20 ומעלה, בנוסף ל־Python 3.10 ומעלה. בקשו מהאייג׳נט לבדוק שהכלים זמינים. לבדיקת הקוד:

```bash
node --test tests/*.test.mjs
python3 tools/check.py
node tools/calculate.mjs examples/comparison.json
```
