# מקורות ובדיקת עדכניות

מפת מקורות שנבדקה ב־28.10.2026. יש לפתוח את המקור מחדש בזמן רכישה; אין כאן תעריפים או זכויות משפטיות מקובעים.

| צורך | מקור | מה לבדוק ומה לא להסיק |
|---|---|---|
| העברת בעלות | [משרד התחבורה](https://www.gov.il/he/service/ownership-vehicles-transfer) | המסלול המתאים לצדדים ולרכב, מסמכים, מגבלות ואגרה. העמוד אותר בחיפוש רשמי; פתיחה ישירה החזירה 403 בעת הכנת הריפו |
| היסטוריית רכב | [מאגר משרד התחבורה](https://data.gov.il/he/datasets/ministry_of_transport/shinui_mivne) | נסועה בטסט, סוגי בעלות ותאריכים בהתאם לכיסוי המאגר. אינו דוח תאונות או אישור זהות בעלים. הפתיחה הישירה דרשה JavaScript; יש לאמת כיסוי ונתונים בשימוש |
| קריאות תיקון | [בירור ריקול](https://www.gov.il/he/service/recall-vehicle) | בדיקה רשמית ובירור אצל היבואן לרכב המסוים. אין התאמה אינו אישור שאין קריאה פתוחה |
| משכונות ושעבודים | [רשות התאגידים](https://www.gov.il/he/service/pawn_perusal) | בירור לפי זהות וסוג הבעלים והנכס. המקור דורש פתיחה ידנית: 403 בכלי המחקר |
| מפרט ואחריות | אתר היבואן, ספר הרכב והצעה כתובה | שנה, דור, מנוע, תיבה, גימור, תחילת אחריות והחרגות |
| ביטוח ומימון | ההצעה האישית, לוח הסילוקין והפוליסה | השוואה על אותם תנאים; מחירי הדגמה אינם הצעות |
